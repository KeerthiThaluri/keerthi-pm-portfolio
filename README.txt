KEERTHI'S PRODUCT MANAGEMENT PORTFOLIO — HOSTING NOTES

This is a self-contained static website. All 8 case studies are built into index.html, so the Read Case Study links do not depend on separate files.

GitHub Pages:
1. Create a PUBLIC repository.
2. Upload index.html and README.txt directly into the repository root (not inside a nested folder).
3. Go to Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose main and /(root), then Save.
6. Wait a few minutes for the published site URL to appear.
